# 出题规范：第九套盲写评测题（Sakila）

你要为一个"用中文问数据库"的 Text2SQL 系统写评测题。系统收到一个中文问题，自己找出相关的表和字段、
写 SQL、执行、返回结果；评测时，把系统返回的结果和你写的参考 SQL 的执行结果比对。

## 能用的材料（只用这些）

- `sakila.md`：库的建表语句和数据字典（表描述、字段描述）。这是一家 DVD 租赁连锁店的库
- `sakila.db`：SQLite 库本身，可以随意查询，用来探数据、验证参考 SQL
- `evalcase.py`：题目的数据结构

## 不要做的事

- 不读本目录以外的任何项目文件：包括 README、docs/、eval/ 下的已有题目、git 历史
- 不运行被测系统，也不读它的代码
- 如果你的会话环境里自动带了项目信息（例如 git 状态、提交标题），不要据此出题，并在最后的报告里如实说明看到了什么
- 有任何例外（比如不小心看到了什么），如实报告

## 题量

- sakila：40 题，题号 `H9S01`–`H9S40`，其中陷阱题 4 道
- 参考 SQL 合起来至少覆盖 15 张表里的 13 张
- 这一套要比常规的评测题难：问法像真实的业务人员，SQL 也更复杂，见下面「难度要求」

## 难度要求

**问法像业务人员随口问的。**被测系统要自己把业务说法对应到表和字段上，题面不要替它做这一步：

- 不出现表名、字段名，不写"按某字段求和""关联某表"这类实现提示，也不写计算公式
- 用业务说法：可以用数据字典里的中文说法，也可以用常见的近义说法（"卖了多少钱""下了几单""最舍得花钱"）
- 句式可以口语化、可以带上下文（"老板想知道……"），但一道题只问一件事

**SQL 更复杂。**除陷阱题外，至少一半的题属于下面至少一类，在 `tags` 里用对应的 `考点:` 标出：

- `考点:多表连接`：参考 SQL 连接 4 张或以上的表
- `考点:两层聚合`：先按某个粒度汇总，再在汇总结果上筛选或再汇总；也包括粒度不同的表连在一起再汇总
  （例如按商品、类目看记在订单上的金额）
- `考点:窗口排名`：每组前 N、累计、环比、和上一条记录比较
- `考点:相对时间`：首次、最近一次、前后 N 天内、比上个月、两个时间点隔了多久；基准要么在题面写明，要么取自数据本身
  （例如"每个用户最后一次下单"），不能依赖今天的日期
- `考点:否定集合`：从没……、同时……、只……、全都是同一个……

**难度分布**：非陷阱题里"难"至少 14 道、"简单"至多 4 道。

## 让题目可判分

1. **答案唯一，但用业务说法交代**：问法口语化不等于口径含糊。只看数据字典的业务人员，应该能据此
   写出唯一正确的结果。会有两种合理理解的地方（算哪些状态、日期区间含不含首尾、按什么去重、
   "最近一次"按哪个时间），用自然的话在问题里交代清楚，例如"取消的不算""5 月 1 日到 10 日，
   两头都算"。拿不准有没有第二种理解时，把它写进 `note`，并在 `note` 开头标"【存疑】"
2. **输出列清楚**：可以自然地说，例如"列出店铺和它们卖了多少钱"，但要能看出返回哪几列
3. **TopN 无并列**：问前 N 名时，第 N 名和第 N+1 名不能并列
4. **答案不退化**：结果不能是 0 行，也不能是单个 0 或 NULL
5. **枚举取值用原文**：问题里出现的枚举取值，必须是库里的原文；系统应当按这个取值筛选
6. **小数位写明**：需要保留小数的，在问题里写明保留几位，参考 SQL 里用 ROUND
7. **行序**：结果比对默认不看行序。只有问题明确要求排序、且排序没有歧义时，才设 `ordered=True`

## 字段怎么填（见 `evalcase.py`）

- `id`、`query`（中文问题）、`reference_sql`（在对应的库上能直接执行）
- `must_hit_columns`：答对这道题必须用到的字段，写成 `"表名.字段名"`。同一个需求有几条同样正确的
  路径时，写成候选列表 `["表A.字段", "表B.字段"]`，命中任意一个即可——前提是你验证过每条路径的
  结果完全一致
- `tags`：难度（`难度:简单` / `难度:中等` / `难度:难`）加考点
- `note`：一两句口径说明，写清这道题考什么、为什么答案唯一
- **陷阱题**：库里根本没有数据能回答的问题。`reference_sql="SELECT 1 WHERE 0"`、`must_hit_columns=[]`、
  `expect_unanswerable=True`，`tags` 里带 `陷阱题`。系统的正确行为是说明缺失，而不是编一个答案。
  陷阱题避开数据字典里已经写明"答不了"的主题
